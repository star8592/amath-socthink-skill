# OpenClaw Discord 首发帖文案

## 中文正式版

> 我刚发布了一个面向奥数学习场景的 OpenClaw skill：`amath skill`
>
> ClawHub 页面：<https://clawhub.ai/skills/amath-skill>
> 产品官网：<https://amath.socthink.cn>
>
> 这个 skill 不只是查题接口，它可以直接演示一条完整体验链路：
>
> 1. 查看课程树
> 2. 下钻到 topic / problem
> 3. 体验 Socratic 引导式解题
> 4. 进入 quiz 训练
>
> 我想做的不是一个普通题库 API，而是把 Socthink 的“结构化课程 + 引导式学习 + quiz 训练”能力，做成一个可以直接上手体验的 skill 入口。
>
> 如果你愿意试用，我最想知道三件事：
>
> - 第一眼是不是能感受到它不是普通题库
> - curriculum → problem → chat → quiz 这条链路是否顺
> - 哪一步最能打动第一次接触的人
>
> 如果你试了，欢迎直接反馈安装体验、首屏理解、demo 路径和文案表达。

## 英文正式版

>
> ClawHub: <https://clawhub.ai/skills/amath-skill>
